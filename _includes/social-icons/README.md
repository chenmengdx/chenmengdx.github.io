# Footer icons

Gmail, LinkedIn, Twitter, Google Scholar, and GitHub SVG paths are from
[Simple Icons v11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons),
published under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md).
Brand names and logos remain the property of their respective owners.

Paths are unchanged. SVG wrappers use currentColor, fixed dimensions, and
aria-hidden because each enclosing link provides its accessible name.
Icons are included inline by Jekyll; no external icon CDN or font is required.
